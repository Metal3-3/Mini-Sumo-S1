An open source Mini Sumo robot. It is a small autonomous robot designed to compete in a ring andpush the opponent robot out of the ring. Equiqqed with 3 sensors 2 qtr1a (for seting up. And designed with inspriation from other chassises.

# Main components
Arduino nano

Genesis sumo shield

MR45 object sensor

QTR 1A

6v 400rpm micro dc motor

silicone wheels
